# Awesome Mizar and MizAR

Discover readable formal mathematics, the Mizar Mathematical Library and automated assistance.

## Start here

- [Mizar project](https://mizar.uwb.edu.pl/) — Find distributions and introductory exercises. Match the system release to its library.
- [Mizar Mathematical Library](https://mizar.uwb.edu.pl/library/) — Browse formalized mathematics and trace an article's imported environment.
- [MizAR](https://mizar.cs.ualberta.ca/~mptp/MizAR.html) — Explore automated assistance for Mizar. Record the service and library version when reporting an experiment. Link availability could not be confirmed in this review.

## First investigation

Choose a small library article and identify its environment declarations, a theorem and the earlier facts used in its proof.

This is a suggested learning exercise. It has not been execution-tested by this collection.
